# Project Glowing Pancake

A free, offline single-player strategy game about founding an AI company. Create a founder, live through school, then build a company or take a CEO appointment. Hire a team, fund experiments and decide which models are ready for customers.

## Build and play on Mac

```sh
./make.sh --package
open "dist/Project Glowing Pancake.app"
```

**New Game** starts the founder campaign. **Playtest Environment → Custom playtest setup & start** opens the configurable development start. Content Studio is the separate repository editor for stories and game content.
