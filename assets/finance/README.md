# Money illustrations

User-supplied SVGs from the supplied `card_money_bank` folder, selected 2026-11-10.
Original bytes, including their embedded rights metadata, are retained in sources.

- `creditcard_red.svg`: **Credit Card**, Algot Runeman, dated 2020-09-26;
  publisher runeman.org; embedded CC0 1.0 declaration.
- `checkbook.svg`: creator unnamed in the supplied file; embedded Openclipart
  public-domain declaration permitting reproduction, distribution and derivatives.
- `receipt.svg`: creator unnamed in the supplied file; the same embedded
  Openclipart public-domain declaration. Runtime receipt removes example shop
  text and is reserved for decorative transaction paper.

The runtime files retain SVG metadata. No external resources, fonts or scripts
are loaded. Red credit-card art is an illustration of a payment method; it does
not create credit or a borrowing mechanic. QML labels show the actual funding
source and actual available money. No real payment-card identifiers are displayed.
These are not AI-generated assets. Other supplied SVGs remain outside the game.
