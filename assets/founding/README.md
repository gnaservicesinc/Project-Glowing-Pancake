# Introduction atmosphere

Three original AI-generated backgrounds, made with the built-in image generator
for this project. Full prompts, hashes and generation disclosure are in
[PROVENANCE.json](PROVENANCE.json). No reference images were supplied.

| Image | Placement and mood |
| --- | --- |
| `california-1997.png` | Mode, birth, family and arrival: dawn over an ordinary California neighborhood; quiet possibility |
| `curiosity-2003.png` | Early childhood through the first teenage circle: a public library computer corner; warm, accessible curiosity |
| `threshold-2015.png` | Later teenage chapters and company founding: a modest shared workspace at blue hour; anticipation and uncertainty |

The first pacing pass uses 2.2-second scene dissolves, a 120ms breath before a
900ms reading-panel fade, and no automatic page advance. Choices and navigation
remain available during transitions. Reduced motion presents everything
immediately. Paper-colored reading panels keep text readable over the paintings.
No camera movement, flashing, or per-letter typewriter effect is used.

The introduction alternates the existing licensed **Gedanklichkeit** and
**Atemübungen** excerpts by **Sascha Ende** (CC BY 4.0), at 60% of the player's
selected music volume. Context changes fade out over 900ms and fade the next
track in over 1.8s. The excerpts already have 1.5s entrance / 2.5s exit fades;
their current 28-second duration remains a first-pass soundtrack limitation.
Music mute/volume preferences continue to apply. Full source credits are in
`assets/audio/CREDITS.json` and in-game Credits.

These timings and scene choices are a starting point for the user's pacing
review. They apply only to setup; the main-game layout remains a later discussion.
