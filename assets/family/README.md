# Childhood markers

Original vector illustrations written for Project Glowing Pancake with Codex on
2026-11-11. These are code-authored SVGs, not generated raster portraits or
third-party artwork. Released under CC0 1.0; the declaration is embedded in each
file. No fonts, scripts, remote resources or personal data are included.

Sprout (under six), sapling (six to twelve) and tree (thirteen to seventeen) are
storybook growth markers, not pictures of a child's face. Adult portraits remain
saved from identity generation and appear only after adulthood.
