# E1A-02 typed trigger forms

The working flow outline has rows for trigger and continuous exit conditions,
their descendants, and expression operands. It also lists the lifecycle and
existing execution nodes. Forms can add and remove grouped conditions, wrap
a condition in negation or a timer, and select a related collection with any,
all or count matching. Member conditions use the relation's registered scope.
The comparison editor exposes an exact entered value or a typed expression.
Expressions support same-scope fact reads and checked add, subtract and ratio
scaling where the shared schema allows them.

Form options, units and factual help use the active registry. The editor
passes exact integer strings into the typed compiler boundary. A stale form
or invalid candidate leaves the working collection and undo history intact.
The form and outline project the same draft that is written to disk.

The optimized Mac editor build passed. The 69 Studio assertions include
wrong-scope and type refusal, integers above the JavaScript exact range,
stale form refusal, timer and related-member restrictions, undo and redo,
and an exact canonical draft save/reopen. The hidden Qt check loaded 15
checkout rows and exercised a comparison edit and undo without saving.
