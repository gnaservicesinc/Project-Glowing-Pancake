# E1A-02 execution and variable forms

The flow outline can insert effects, delays, ordered sequences, reusable
subflows, news, dialogue, results and weighted branches on a chosen link.
Authors edit numbered effects using registry-supplied targets and arguments.
Choice requirements and variable assignments reuse the condition and
expression forms. Variable declarations use typed values, units and defaults.
Node, choice and variable renames update typed references atomically.
Removing a node or branch prunes only newly unreachable nodes and can be
undone. The shared compiler rejects invalid scopes, targets and links before
the working document changes.

The Apple arm64 optimized editor build passed. The Studio executable passed
179 assertions. The authored company flow applies two ordered effects, enters
a two-day sequence wait, resumes into a reusable subflow from an exact saved
checkpoint, and reaches the chosen dialogue result and news. Tests also cover
seeded branching, scoped assignments, atomic renames, and rejected target
and declaration edits. Five focused CTests passed for the Studio, flow runtime,
save integration, weighted branches and variables.

The hidden Qt view loaded 15 library rows and moved through the flow outline
with the Down key. Screen reader and 200% text scaling remain author
qualification work. The forms use the existing content and save formats.
E1A-01 and M1-06 prerequisite gates remain open.
